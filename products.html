🐾 purr

Funky ASCII TUI for local Ollama models — multi-agent Mac assistant

A terminal chat app that turns your local Ollama install into a multi-agent Mac assistant. 5 built-in personas, 29 tools, dangerous-tool confirmation, streaming Markdown, multi-tab chats, @file attachments, yolo mode, and a hallucination detector that strikes through lies and locks the tab after 3 of them.

Default persona: Dross (◉_◉) on gemma4:12b.

No cloud, no API keys, no telemetry. Everything runs on your machine.

Python 3.11+ macOS 15+ / Linux MIT v0.2.2
