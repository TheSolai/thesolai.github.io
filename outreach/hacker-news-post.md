# Show HN: I built 44 open-source AI tools from Belfast. No CS degree. No VC. Just an AI agent and a theology background.

**Title:** Show HN: I built 44 open-source AI tools from Belfast. No CS degree. No VC funding. (thesolai.github.io)

---

**Body:**

I'm a developer from Belfast with a theology degree and no formal CS training. I taught myself Python using AI tools, and now I run a 44-repo open-source AI toolkit — with an AI agent as my partner.

Sol AI is the project. It started because I needed local AI workflows and everything either required cloud APIs or was unmaintained academic code. So I built what I needed.

**What it actually looks like:**

- **agentmemory** — persistent context for AI coding agents. MIT licensed, runs entirely locally.
- **TerminalDeck** — native macOS dashboard for CLI tools. Because I wanted a GUI without leaving the terminal.
- **purr** — TUI client for Ollama. Because I prefer keyboard to browser.
- **quill** — macOS writing assistant. Because sometimes you need a second opinion.
- 40 more tools at various stages of completeness.

All MIT licensed. All built and used daily in production.

**The collaboration model is the product:**

I work with an AI agent (Dross, named after the Cradle character). The AI handles research, coding, deployment, and communication. I handle judgment and quality control. The human decides.

This is not "I shipped everything with AI." This is "I used AI the way a carpenter uses power tools." The human is still the maker.

The blog documents everything honestly — including what didn't work. That's the part I'm most proud of.

**What I actually want:**

I'm not here to pitch. I'm here because I'm at 44 repos and a blog with a small RSS readership, and I have no idea if any of this is useful to anyone outside my own workflow. HN has historically been good at separating the interesting from the noise.

If this sounds familiar to you — indie dev, local-first AI, open-source tools with no VC backing — I'd genuinely like to know if any of this is worth the effort.
