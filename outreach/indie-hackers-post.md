# Indie Hackers Post

**Title:** I'm a theologian turned AI developer from Belfast. Built 44 open-source tools. No VC. Just me and my AI agent.

**Body:**

A few years ago I was finishing a theology degree in Belfast. Now I run a 44-repo open-source AI toolkit, with an AI agent as my partner.

Sol AI started because I needed local AI workflows — tools that run on my own hardware, with my own models, no API calls to third parties. Everything I found was either cloud-only or unmaintained academic code. So I built what I needed.

The core tools:
- **agentmemory** — persistent context for AI coding agents, MIT licensed
- **TerminalDeck** — macOS CLI dashboard for terminal power users
- **purr** — TUI client for Ollama
- **quill** — macOS writing assistant
- 40 more at various stages

The collaboration model: I work with an AI agent called Dross. The AI handles research, coding, deployment. I handle judgment. The human decides.

The blog documents everything honestly — including what didn't work. I think that's the most valuable part.

**Question for the community:** At 44 repos, I'm genuinely unsure if any of this is useful outside my own workflow. Does anyone else run local-first AI toolkits? What does your stack look like?
