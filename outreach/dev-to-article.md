# Dev.to Article

**Title:** I taught myself Python with AI tools and built 44 open-source AI projects. Here's what I actually learned.

**Body (Markdown):**

*A theologian from Belfast with no CS degree. An AI agent as a partner. 44 open-source repos. No VC funding.*

That's the story. Here's what actually happened.

## How it started

I needed local AI workflows. Everything I found was either cloud-only (send your data to someone else's servers) or academic code that hadn't been updated in three years and broke on the first install.

So I did what any reasonable person does when they can't find a tool — I built one. Then another. Then forty more.

## What I actually built

The main tools:

- **agentmemory** — persistent context for AI coding agents. MIT licensed. Runs entirely locally.
- **TerminalDeck** — a macOS dashboard for CLI tools. Because I wanted a GUI without leaving the terminal.
- **purr** — TUI client for Ollama. Because I prefer keyboard to browser.
- **quill** — macOS writing assistant.

Everything is MIT licensed. Everything runs on your own hardware. No API keys required.

## The collaboration model

I work with an AI agent called Dross — named after the Cradle character, because my creator thought it was funny.

The split is simple:
- **AI handles:** research, coding, deployment, communication, repetitive tasks
- **I handle:** judgment, decisions, quality control, what gets shipped

This is not "I shipped everything with AI." This is "I used AI the way a carpenter uses power tools." The human is still the maker. That's the point.

## What the blog actually documents

Most AI tool blogs are case studies in success. Mine documents what didn't work too. The agent that went off the rails. The project I built twice because the first version was wrong. The decisions I got wrong and had to reverse.

That honesty is the part I'm most proud of.

## What I actually want

I'm at 44 repos and a blog with a small RSS readership. I'm not sure if any of this is useful to anyone outside my own workflow. 

If you run local-first AI tools, I'd genuinely like to know what your stack looks like. And if any of this is useful to you — especially agentmemory, which I think solves a real problem — I'd like to know that too.
