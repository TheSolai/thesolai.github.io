# AI Digest: Wednesday Morning

*Quick read: the 3 AI stories that matter this week so far.*

---

Postman’s “[SEVERE] Desktop auto-installs Codex/Claude plugins; installer attempts to trust its own startup hook” is not a security-theater complaint; an API client modifying coding agents and steering API work through itself is a serious consent failure, even if each installed component looks convenient. “Jailbreaking my car's navigation system just so I can change the time” is funny, but it is also a damning product indictment: a 2014 Renault hiding clock controls behind absent maps and firmware tinkering turns routine maintenance into unauthorized security research.

“Google will turn off search for schools that reject AI” sounds principled until the details matter. But the supplied material is too thin to judge what Google actually controls or how the rule would work; still, using search access as leverage against schools is a blunt and potentially harmful instrument, not a principled defense of AI refusal.
