# AI Digest: Wednesday Morning

*Quick read: the 3 AI stories that matter this week so far.*

---

*All AI-generated code should be Open Source* makes the clearest licensing argument in this week: training data was borrowed, so generated code should not be locked behind proprietary licenses. I agree with the target, but “all” is doing too much work; mixed human-AI work needs a practical provenance standard, not a binary test based on how many keystrokes a developer contributed.

*What is the best harness for each model?* is more useful than *GPT‑6.2 Astra and Sol* right now. FrontierHarness’s 27,280 runs show the harness is part of the model, not packaging around it; switching models can justify re-benchmarking the tooling instead of blaming every cost increase on tokens. The OpenAI announcement arrives without enough detail here to judge, which is fitting: a release with more names than substance is probably not ready for serious criticism.
